KONSEP & ARSITEKTUR UTAMA SISTEM

BAGANOVA Smart Monitoring System

Website BAGANOVA Smart Monitoring System merupakan website berbasis internet yang dirancang sebagai pusat pemantauan dan pengendalian alat bagan tancap otomatis untuk membantu nelayan dalam proses pengangkatan jaring. Website ini dapat diakses melalui smartphone maupun laptop selama terhubung dengan internet, sehingga pengguna dapat memantau kondisi alat tanpa harus selalu berada di dekat perangkat.

Sistem bekerja dengan mengintegrasikan mikrokontroler ESP32, sensor berat (load cell) yang dihubungkan dengan modul HX711, motor DC gearbox 12V, dan Firebase Realtime Database sebagai media komunikasi antara perangkat keras dan website. Sensor berat berfungsi mendeteksi beban pada jaring secara langsung, kemudian data tersebut dikirimkan oleh ESP32 ke Firebase dan ditampilkan pada dashboard website secara realtime dalam bentuk nilai berat, batas maksimal beban, serta status pengangkatan jaring.

Pengguna dapat mengatur batas maksimal berat sesuai kebutuhan melalui website. Ketika beban jaring telah mencapai batas yang ditentukan, ESP32 secara otomatis memberikan perintah kepada motor untuk menggulung tali utama dan mengangkat jaring. Selama proses tersebut, website menampilkan perubahan status alat: mulai dari kondisi siaga, proses pengangkatan, hingga jaring mencapai posisi atas.

Sistem juga dilengkapi dengan fitur pemantauan koneksi perangkat, indikator kondisi motor, riwayat pembacaan berat, serta kontrol manual untuk membantu pengguna melakukan pengendalian atau menghentikan proses apabila diperlukan. Sementara itu, proses penurunan jaring tetap dilakukan secara manual untuk menyederhanakan mekanisme dan mengurangi kompleksitas sistem.

Rem Mekanis Mengunci Aman
01

Sensor Membaca Gaya Tarik

Load cell yang terpasang secara inline pada tali derek utama membaca tarikan total secara berkelanjutan dengan konversi 24-bit.

02

Penerimaan Sinyal ESP32

Mikrokontroler ESP32-WROOM-32 menerima paket sinyal digital berkecepatan 20 sampel per detik untuk diproses secara lokal.

03

Penyaringan Ombak & Angin

Algoritma filter komputasi meredam lonjakan beban sesaat akibat ombak laut sehingga tidak memicu pengangkatan prematur.

04

Validasi Ambang Batas Stabil

Ketika beban akumulasi ikan melampaui target ambang batas dan kondisi stabil minimal 3 detik, sinyal pemicu aktif.

05

Penggulungan Tali oleh Winch

Motor winch DC torsi tinggi mulai memutar drum penggulung untuk menarik satu tali utama ke atas secara mulus dan terkendali.

06

Pengangkatan 4 Sudut Simetris

Rangka pembagi (square spreader bridle) menyalurkan tarikan tali utama secara merata ke 4 tali sudut jaring bagan.

07

Penghentian Otomatis Limit Switch

Begitu rangka jaring mencapai batas elevasi maksimal, sakelar pembatas memutus arus motor dan rem mekanis mengunci posisi.

08

Penurunan Manual oleh Operator

Setelah hasil tangkapan diambil nelayan, penurunan jaring kembali dilakukan secara manual via web untuk menjamin keselamatan.

STANDAR OPERASIONAL PROSEDUR (SOP)

4 Langkah Pengoperasian Smart Bagan bagi Nelayan

Panduan ringkas bagi operator nelayan di geladak bagan untuk memastikan operasi penangkapan berjalan aman dan optimal.

LANGKAH 1

Pemeriksaan Awal & Kalibrasi Tare

Pastikan jaring terendam kosong di dalam air. Buka menu Pengaturan, periksa apakah beban terbaca ~20 kg (berat mati jaring terendam), lalu tekan Kalibrasi Tara Baseline.

LANGKAH 2

Uji Limit Switch & E-STOP Darurat

Tekan tuas sakelar pembatas mekanis (limit switch) secara manual untuk memastikan lampu indikator di dashboard menyala hijau (siaga), dan pastikan tombol E-STOP merah mudah dijangkau.

LANGKAH 3

Pengaktifan Otomasi Pengangkatan

Atur target ambang batas panen (default 85 kg). Sistem akan otomatis memonitor gaya tarik pada tali utama dan langsung memicu motor winch begitu target beban ikan tercapai secara stabil.

LANGKAH 4

Penurunan Jaring Kembali Secara Manual

Setelah hasil tangkapan selesai diserok nelayan ke geladak, turunkan kembali jaring secara manual menggunakan tombol Turunkan Jaring di website demi verifikasi keamanan area.

TANYA JAWAB UMUM

Pertanyaan yang Sering Diajukan Seputar BAGANOVA

ESP32 menjalankan algoritma filter digital rata-rata bergerak (Moving Average Window 15 sampel). Sentakan ombak laut bersifat fluktuatif naik-turun dalam fraksi detik dan segera diredam. Sebaliknya, akumulasi ikan di dalam kantong jaring menghasilkan kenaikan beban yang konsisten dan stabil. Sistem hanya akan memicu motor jika beban melampaui target dan nilainya bertahan stabil minimal 3 detik kontinu.

Ini merupakan protokol keselamatan maritim (human-in-the-loop safety protocol). Menurunkan jaring ke laut membutuhkan kepastian visual bahwa tidak ada perahu perintis nelayan di bawah bagan, tidak ada tali yang terlilit, dan jaring telah benar-benar dikosongkan. Oleh karena itu, operator nelayan mempertahankan kendali penuh untuk menurunkan jaring melalui tombol kendali di website.

Tersedia tombol EMERGENCY STOP (E-STOP) berwarna merah menyala baik di dashboard website maupun sakelar fisik di instalasi bagan. Menekan tombol E-STOP seketika memutus aliran listrik ke motor, dan mekanisme pengereman otomatis internal winch (cone friction brake) langsung mengunci posisi jaring agar tidak jatuh.

Mikrokontroler ESP32 bertindak sebagai Access Point mandiri lokal (Local Gateway). Dashboard web dapat diakses langsung oleh operator melalui jaringan Wi-Fi lokal bagan tanpa memerlukan kuota atau sinyal internet eksternal. Selain itu, seluruh logika ambang batas dan proteksi limit switch berjalan mandiri (stand-alone) di dalam memori firmware ESP32.
